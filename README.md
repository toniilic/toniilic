# Toni Ilić

I build web software that ships. I have built 10 live products on my own and still run them. My stack is Laravel, Vue and Django, and I add AI features to apps you already run.

I work full-time and take on a small number of side projects alongside that role through my studio, [AgiCAD](https://agicad.com). These are scoped builds, audits and small retainers. I work from Rijeka, Croatia (CET) and work async, with evening overlap for US time zones.

## What I take on

- **Web apps and SaaS:** Laravel, Symfony and Django backends, Vue 3 front ends, Stripe billing, admin panels and queues.
- **AI added to existing apps:** LLM features with streaming, spend caps, rate limits, fallback across providers and EU-aware data routing.
- **Analytics and tracking:** GA4, GTM (web and server-side), Meta CAPI, Google Ads conversions and Consent Mode, covering audits, rebuilds and fixes.
- **Audits and rescue:** legacy PHP and CodeIgniter upgrades, Vue 2 to 3 migrations, WooCommerce fixes, Core Web Vitals and production incidents.
- **Scraping and data pipelines:** Playwright scrapers with change detection and circuit breakers, plus affiliate and product feeds.

## How I work

1. **Plain words.** I write proposals, updates and docs that a non-engineer can read.
2. **Show, don't tell.** Every week ends with software you can click.
3. **Say no early.** If a feature or a deadline is a bad idea, you hear about it in week one.
4. **Build for the next team.** You get the code in your own repo, with tests and docs that let someone else take over.
